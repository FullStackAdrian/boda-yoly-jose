# Yoly & Jose 💍

Página web estática para la boda de Yoly y Jose.

## Desarrollo

No requiere build ni dependencias. Puedes probarla con:

    python3 -m http.server 8000

Después abre http://localhost:8000.

## GitHub Pages

El despliegue se realiza automáticamente con GitHub Actions al hacer push a main.
